Tools

Three open-source checks I run on my own work, as a CLI and as a Claude Code skill.

  • motion-audit

    Audit how a running web UI moves in a real browser: missing hover, press and focus feedback, snapping transitions, jank, wrong easing and reduced-motion gaps.

    What it finds

    • Buttons where nothing visible changes on hover or press
    • Transitions that snap, ease in late or animate layout (width, top)
    • Elements that still move, or loop forever, with reduced motion on

    Install as a CLI

    npm i -D motion-audit playwright
npx playwright install chromium
npx motion-audit http://localhost:3000

    Install as a Claude Code skill

    claude plugin marketplace add NahuelMosse/motion-audit
claude plugin install motion-audit@motion-audit

    npm package of motion-audit GitHub repository of motion-audit

  • http-attack

    Adversarially probe a local HTTP API for what unit tests miss: 5xx on bad input, races on creates, unbounded bodies, SQL injection, IDOR and CSRF.

    What it finds

    • A search that reaches LIKE unescaped: ?q=% matches rows
    • Malformed JSON answered with a 500 and a stack trace
    • A 1 MB body accepted where the answer should be 413

    Install as a CLI

    npm i -D http-attack
npx http-attack http://127.0.0.1:3000

    Install as a Claude Code skill

    claude plugin marketplace add NahuelMosse/http-attack
claude plugin install http-attack@http-attack

    npm package of http-attack GitHub repository of http-attack

  • migrations-safe

    Write and review database migrations that keep data, running code and busy tables safe, across PostgreSQL, MySQL, SQLite, SQL Server, Oracle and Db2.

    What it finds

    • A dropped column the running code still reads or writes
    • A NOT NULL column with no default added to a populated table
    • An index built without CONCURRENTLY, blocking writes

    Install as a CLI

    npm i -D migrations-safe
npx migrations-safe lint db/migrations/

    Install as a Claude Code skill

    claude plugin marketplace add NahuelMosse/migrations-safe
claude plugin install migrations-safe@migrations-safe
